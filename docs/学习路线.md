### 1. FastAPI 基础

**要掌握到什么程度：** 能写一个接收 POST 请求、返回 JSON 的接口

**要学的：**
- 路由装饰器（`@app.get`、`@app.post`）
- 请求参数（path、query、body）
- Pydantic 模型做参数校验
- `async def` 和普通 `def` 的区别
- `uvicorn` 启动服务

**不需要学的：** 中间件、WebSocket、依赖注入、OAuth2 等高级功能（用到再学）

**推荐资源：**
- FastAPI 官方教程（中文）：https://fastapi.tiangolo.com/zh/tutorial/
- 只看 "First Steps" 到 "Request Body" 这几节，大约 30 分钟

### 2. RAG 原理

**要掌握到什么程度：** 能画出 RAG 的完整流程图，能解释每一步在干什么

**要学的：**
- 什么是 Embedding（文本向量化）—— 把文字变成一串数字，语义相近的文字距离近
- 什么是向量数据库 —— 存向量、按相似度检索
- RAG 的完整流程：加载 → 切段 → 向量化 → 存储 → 检索 → 生成
- 切段策略（chunk size、overlap）对效果的影响

**不需要学的：** Embedding 模型的训练原理、向量数据库的底层实现（ANN、HNSW 算法）

**推荐资源：**
- 搜索 "RAG 原理 图解" 或 "RAG tutorial 中文"
- B 站搜 "RAG 从零实现"，看一个 20-30 分钟的视频就够
- 重点理解这张图：

```
文档 → 切段 → Embedding → 向量数据库
                                ↑ 检索
用户问题 → Embedding ───────────┘
                                ↓
            检索到的段落 + 用户问题 → 大模型 → 回答
```

### 3. 大模型 API 调用（OpenAI SDK 格式）

**要掌握到什么程度：** 能用 Python 调通一个大模型 API，发消息、收回复

**要学的：**
- Messages 格式：`system`、`user`、`assistant` 三种角色
- 什么是 temperature（控制随机性）
- 什么是 token（大模型的计费/限制单位）
- 流式输出（streaming）是什么

**不需要学的：** 微调、训练、tokenizer 的底层实现

**推荐资源：**
- 阿里百炼文档：看 "快速开始" 部分
- 核心代码就这几行，理解它就够了：

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的key",
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1"
)

response = client.chat.completions.create(
    model="qwen-max",
    messages=[
        {"role": "system", "content": "你是一个股票分析师"},
        {"role": "user", "content": "帮我分析一下茅台"}
    ]
)

print(response.choices[0].message.content)
```

### 4. Function Calling / Tool Use

**要掌握到什么程度：** 理解大模型怎么"调用工具"，能写一个带工具的对话

**要学的：**
- 大模型本身不能执行代码，它只是输出"我想调用 xxx 函数，参数是 yyy"
- 你的代码收到这个输出后，真正去执行函数，把结果返回给大模型
- 完整流程：

```
用户："帮我查茅台今天的股价"
  ↓
大模型（不知道股价，但知道有个工具可以查）
  ↓ 输出：调用 get_realtime_quote(symbol="600519")
  ↓
你的代码：执行这个函数，拿到结果 1443.31
  ↓ 把结果传回大模型
  ↓
大模型："茅台今天收盘价 1443.31 元，较昨日下跌 0.73%"
```

- tools 参数的 JSON Schema 格式（告诉模型有哪些工具可用）

**不需要学的：** 各家 API 的格式差异（OpenAI / Anthropic / 百炼，核心概念一样）

**推荐资源：**
- 搜索 "OpenAI function calling 教程 中文"
- 百炼文档的 "工具调用" 章节

## 第二优先级：项目做到一半会用到的（下周）

### 5. ChromaDB 基本操作

**要掌握到什么程度：** 会创建集合、添加文档、查询相似文档

**要学的：**
- `chromadb.Client()` 创建客户端
- `collection.add()` 添加文档和向量
- `collection.query()` 查询最相似的文档
- 持久化存储（数据存到磁盘而不是内存）

**推荐资源：**
- ChromaDB 官方 Getting Started，10 分钟能看完

---

### 6. Pydantic 数据模型

**要掌握到什么程度：** 能定义一个模型类，做参数校验和 JSON 序列化

**要学的：**
- `BaseModel` 定义数据结构
- 字段类型（str、int、float、Optional、List）
- `.model_dump()` 转字典
- `.model_validate()` 从字典创建

**推荐资源：**
- FastAPI 教程里就会教，不用单独找

---

### 7. Python async/await

**要掌握到什么程度：** 理解为什么 FastAPI 要用 async，能写 async 函数

**要学的：**
- 同步 vs 异步：同步是排队等，异步是发出请求后先干别的
- `async def` 定义异步函数
- `await` 等待异步操作完成
- 什么时候用 async（IO 操作：网络请求、数据库读写）
- 什么时候不用（CPU 计算）

**不需要学的：** 事件循环原理、asyncio 底层实现

## 第三优先级：面试要聊的（项目做完后）

### 8. Prompt Engineering 基础

**要掌握到什么程度：** 能解释常见的 prompt 技巧，知道什么时候用

**要学的：**
- Few-shot（给几个例子让模型学着做）
- Chain of Thought（让模型一步步思考）
- System Prompt 的作用（设定角色和规则）
- Prompt 模板化（用 Jinja2 或 f-string）

---

### 9. Agent 架构概念

**要掌握到什么程度：** 能画出 Agent 的执行循环，能解释 ReAct 模式

**要学的：**
- Agent = LLM + Tools + Memory
- ReAct 模式：思考（Reasoning）→ 行动（Action）→ 观察（Observation）→ 循环
- 单 Agent vs 多 Agent 的适用场景
- Agent 的局限性（幻觉、工具调用失败、死循环）

**推荐资源：**
- 搜索 "ReAct Agent 原理"
- 看一篇就够，理解循环就行

---

### 10. 向量检索原理（面试加分项）

**要掌握到什么程度：** 能解释余弦相似度，知道近似最近邻是什么

**要学的：**
- 余弦相似度：两个向量方向越接近，值越大（1 = 完全一样，0 = 无关）
- 精确搜索 vs 近似搜索（ANN）：数据量大时用近似搜索换速度
- 常见算法名字知道就行：HNSW、IVF

**不需要学的：** 算法实现细节

## 学习方法

1. **不要系统学，要按需学。** 项目下一步需要什么就学什么，别从头看完整本书
2. **每个概念看完，用自己的话说一遍。** 说不清楚就是没懂
3. **看完就写代码验证。** 别只看不练
4. **记笔记，但只记让你意外的东西。** "FastAPI 用装饰器定义路由"不用记，"async def 和 def 在 FastAPI 里性能差别不大因为它会自动放到线程池"值得记
